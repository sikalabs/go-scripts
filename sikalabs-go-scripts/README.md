# sikalabs-go-scripts

Single binary containing all scripts from this repository as subcommands.

## Install (master)

```
go install github.com/sikalabs/go-scripts/sikalabs-go-scripts@master
```

## Example Usage

```bash
sikalabs-go-scripts --help
```

```bash
sikalabs-go-scripts example-hello-world --name "Dela"
```
